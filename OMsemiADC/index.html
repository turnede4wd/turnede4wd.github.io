GitHub Pages 靜態託管

純前端靜態網頁架構，可直接推送至 GitHub Repository 並啟用 GitHub Pages 發布。

GitHub Pages 檔案放置與部署步驟

  1. 在 GitHub 建立儲存庫（例如 esp32-web-flasher），將 index.html 放在儲存庫根目錄。
  2. 將 merged-binary.bin 放在同一目錄（例如 ./firmware/merged-binary.bin），並建立對應的 manifest.json。
  3. 若 merged-binary.bin 檔案較大，建議改放於同儲存庫的 GitHub Releases 附件，並於 manifest.json 填入對應下載網址。
  4. 前往 GitHub 儲存庫的 Settings > Pages，選擇分支（如 main）與資料夾（/ (root)）儲存並啟用 HTTPS。
專案目錄建議結構：
├── index.html
├── manifest.json
└── firmware/
    └── merged-binary.bin

提示：esp-web-tools 需要透過 manifest.json 指定 merged-binary.bin 的路徑與起始位址（通常為 0x0），且必須在 https://（或 localhost）下才能存取 Web Serial。
